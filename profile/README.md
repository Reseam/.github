Reseam is a patcher for Android apps. In Reseam Manager you choose an app, select patches and install the patched app.

## Get started

- [Download Reseam Manager](https://reseam.app/download/) for Android, Windows or Linux.
- [Browse the patches](https://reseam.app/patches/) for each supported app.
- [Patch in your browser](https://reseam.app/patch/) if you can't install Reseam Manager.
- [Request a patch](https://reseam.app/requests/) or vote on existing requests.
- [Write your own patches](https://reseam.app/docs/) with [`patches-template`](https://github.com/Reseam/patches-template).

## Repositories

These are read-only mirrors of [git.reseam.app](https://git.reseam.app/reseam). For requests and bug reports, use [reseam.app/requests](https://reseam.app/requests/).

| Repository | What it is |
|---|---|
| [`reseam`](https://github.com/Reseam/reseam) | Patch engine, `reseam` CLI and patch SDK |
| [`patches`](https://github.com/Reseam/patches) | The official patches |
| [`manager`](https://github.com/Reseam/manager) | Reseam Manager for Android, Windows and Linux |
| [`patches-template`](https://github.com/Reseam/patches-template) | Template for your own patches |
| [`website`](https://github.com/Reseam/website) | reseam.app and the docs |
| [`api`](https://github.com/Reseam/api) | api.reseam.app |
| [`gmscore`](https://github.com/Reseam/gmscore) | GmsCore for patched apps, a microG fork |
| [`translate`](https://github.com/Reseam/translate) | Translation engine used by the API |
| [`relay`](https://github.com/Reseam/relay) | Posts releases and announcements to our socials |
| [`bot`](https://github.com/Reseam/bot) | Discord bot |
| [`ci`](https://github.com/Reseam/ci) | CI image |
